почему -4 а не -3: // округляет вниз, то есть в сторону минус
бесконечности, а не просто отбрасывает дробную часть. поэтому
из -3.5 получается -4

про / и //
/ всегда дает float, даже когда делится ровно, например 8/2=4.0
// округляет вниз, для положительных это как отбросить остаток
17//5=3

про остаток
% это то что остается после деления. 17%5=2 потому что 17=3*5+2.
еще есть формула a == (a//b)*b + a%b

про float
:.2f меняет только вывод на экран, но не само число в памяти
0.1+0.2 внутри это 0.30000000000000004, потому что 0.1 и 0.2
нельзя точно записать в двоичном виде. :.2f покажет 0.30 но
если потом считать дальше, ошибка никуда не денется
