average для пустого списка и [2,4,6].

Ошибка:
Специально убрал abs() в функции sum_digits.
Тогда sum_digits(-507) вернуло -12, и тест выдал AssertionError.
Потом вернул abs() обратно, чтобы тесты снова проходили.

Объяснение:
return возвращает результат в код (чтобы его можно было сохранить), а print просто показывает на экран.
Параметр это имя в def, локальная переменная создается внутри функции.
assert проверяет условие и падает, если оно неверное.
